# 01　问题与约束

> 本文是报告第 3 节的基础。每条约束都给出：原文、形式化、判定口径、代码位置、对应测试用例。
> 原文出自 `附件1.docx` 的 P12–P18（题面 PDF 仅 3 页，详细约束在附件 1）。

---

## 1. 问题定义

**集合**

| 符号 | 含义 |
|---|---|
| `I` | 全部货物件数，`|I| = 300` |
| `K` | 货物型号集合 `{G1..G5}`，每型有尺寸 `(l_k, w_k, h_k)`、重量 `m_k`、件数 `n_k` |
| `V` | 车型集合 `{车型1, 车型2}`，每型有内尺寸 `(L_v, W_v, H_v)`、载重 `M_v`、成本 `c_v` |
| `B` | 车辆实例集合（决策结果，`|B|` 即车辆数） |

**决策变量**

对每件货 `i`：所在车辆 `b_i ∈ B`、放置坐标 `(x_i, y_i, z_i)`、姿态 `o_i ∈ O(kind_i)`（一个 `(l, w, h)` 的排列）。

**目标**（按题面三个子问题）

1. 单车满载率最大化：`max (Σ v_i) / (Σ V_b)`
2. 装完且车辆数最少：`min |B|`，约束 `Σ_{i: b_i=b} v_i ≤ V_b`
3. 多车型：`min |B|` 与 `min Σ c_{b}` 分别求解并对比

**坐标系**：题面要求「以车厢右后下为坐标原点」。本项目内部以左前下为原点，导出解时做 `y → W − y − w` 变换（见第 5 节）。

---

## 2. 下界推导

```
下界车辆数 = max( ⌈Σ v_i / V_v⌉ , ⌈Σ m_i / M_v⌉ )
```

| 车型 | 体积下界 | 重量下界 | 下界 | 成本 |
|---|---|---|---|---|
| 车型1（19.404 m³ / 6000 kg） | ⌈28.735/19.404⌉ = 2 | ⌈4110/6000⌉ = 1 | **2** | 900 |
| 车型2（41.650 m³ / 10000 kg） | ⌈28.735/41.65⌉ = 1 | ⌈4110/10000⌉ = 1 | **1** | 700 |

下界的算术内核（`total_le`）已在 Lean 4 中机器验证，见 `lean/Boxpack.lean`。
**它不是最优解，只是「不可能更好」的证明**——实际车辆数与下界的差距，才是算法的优化空间。

## 3. 十条约束

### C1　正交摆放

- **原文（P15）**：「必须保持正交摆放（棱与箱体棱平行）」
- **形式化**：每件的边平行于坐标轴，姿态为原始尺寸的排列。
- **判定**：`sorted(l, w, h) == sorted(l_k, w_k, h_k)`
- **代码**：`src/constraints.py::check_orientation`（求解器侧 `pack_lib.orients`）
- **用例**：`test_constraints.py::case_C1`

### C2　不重叠

- **原文（P15）**：「货物之间、货物与箱体之间不得重叠」
- **形式化**：任意 `i ≠ j`，三轴投影至少一轴不相交。
- **判定**：区间相交测试（`x` / `y` / `z` 三轴同时相交即重叠）
- **代码**：`check_overlap`
- **用例**：`case_C2`
- **说明**：与 C10 合起来才完整覆盖「货物与箱体不重叠」。

### C3　刚性、不可拆分

- **原文（P15）**：「所有货物均为刚性长方体，不可挤压、不可拆分」
- **判定**：每型件数与规格表一致，且不出现未知型号。
- **代码**：`check_counts`
- **用例**：`case_C3`
- **实现位置**：`run_baselines.py::verify_all` 中跨车统计（不能逐车查）。

### C4　标准件可任意方向、可堆叠

- **原文（P12）**：「标准件：长方体纸箱，可任意方向摆放，可堆叠，无特殊约束」
- **判定**：六种排列均合法。
- **代码**：`pack_lib.orients`（非 oriented 类型返回全排列）
- **说明**：题面**未规定**非易碎件的底面接触比 → 见假设 A1。

### C5　易碎件仅单层、不可堆叠

- **原文（P13）**：「易碎件：仅允许单层放置，不可堆叠」
- **形式化**：不存在货物 `j` 直接坐落在易碎件 `i` 的顶面上。
- **判定口径（重要）**：`z_j == z_i + h_i` 且水平投影有交 → 违规。
  **悬空覆盖不计**：若 `j` 由其他件支撑、只是悬在 `i` 上方而不接触，不算「堆叠」——那属于 A1 支撑比管辖的范围。
- **代码**：`check_fragile_single_layer`（求解器侧：`feasible` 中「易碎件不可承重」）
- **用例**：`case_C5`
- **口径变更记录**：初版按「上方不得有任何覆盖」判定，在 A1=0 时误报 16 条；厘清「堆叠 = 承重关系」后改为直接接触判定。

### C6　易碎件底面 100% 贴合，且只能落在标准件或地面

- **原文（P13）**：「摆放时底面必须完全贴合箱体底面或其他**标准件**顶面」
- **形式化**：`z_i = 0`，或 `i` 的底面被高度相接的下层件完全覆盖，且每个下层件的类型为 `standard`。
- **判定**：离散化底面网格，覆盖率必须为 1.0；下层件类型必须全为 `standard`。
- **代码**：`check_fragile_support`
- **用例**：`case_C6_ratio`（68.6% 覆盖）、`case_C6_kind`（落在定向件上）
- **实测影响**：这是本算例的**主要瓶颈**。30 件易碎件需要 10.50 m² 的合规落点，占车厢底面 63.0%；而底层大面积被 90 件定向件占据，顶面不平整 → 27 件被挤到第二辆车。

### C7　定向件仅一种摆放姿态

- **原文（P14）**：「定向件：有明确方向要求（如"向上"标识），仅允许一种摆放姿态」
- **判定**：`(l, w, h) == (l_k, w_k, h_k)`，不允许排列。
- **代码**：`check_orientation`（oriented 分支）
- **用例**：`case_C7`
- **注意**：姿态改动后尺寸仍是原尺寸的排列，C1 抓不到，必须由 C7 单独判定。

### C8　定向件上层货物重心不得超出其投影

- **原文（P14）**：「可堆叠但上层货物**重心不得超出下层投影范围**」
- **解读**：约束对象是「堆在定向件之上的货物」。对每个直接坐在定向件 `o` 上的货物 `b`，其底面重心投影点必须落在 `o` 的顶面矩形内。
- **形式化**：`(x_b + l_b/2, y_b + w_b/2) ∈ [x_o, x_o + l_o] × [y_o, y_o + w_o]`
- **代码**：`check_oriented_cog`（求解器侧 `feasible` 内独立实现一份）
- **用例**：`case_C8`（重心 x=90 > 80，越界）
- **备注**：本条在初版实现中**完全缺失**（求解器与校验器同时没有），开发过程中由独立校验器发现并补齐。这是「能力分离」有效的直接证据。

### C9　下层承重 ≤ 500 kg/m²

- **原文（P17）**：「下层货物承重上限为 500kg/平方米，超重则不允许堆叠」
- **形式化**：对每件 `o`，`(m_o + Σ 上方分摊重量) / (l_o·w_o·10⁻⁴) ≤ 500`
- **判定**：按接触面积比例分摊上层重量（假设 B1：不做堆叠链传递）。
- **代码**：`check_pressure`
- **用例**：`case_C9`（合成用例，200 kg 件）
- **活跃性分析（重要）**：本算例货物平均密度 `4110 / 28.735 = 143 kg/m³`。堆满可用高度 247 cm 的理论最大承压约为 `143 × 2.47 = 353 kg/m² < 500`。**因此 C9 在本题数据下不具约束力**，任何合法堆叠都不会触发它。这一结论可写进报告的「约束活跃性」一节。

### C10　高度、顶部余隙、载重

- **原文（P17–P18）**：「货物高度不得超过车厢高度，且顶层货物距车厢顶部预留不小于 3cm 安全间隙」
- **形式化**：`∀i: z_i + h_i ≤ H_v − 3`；`Σ m_i ≤ M_v`
- **代码**：`check_bounds`
- **用例**：`case_C10`
- **说明**：把「3 cm 余隙」实现为「可用高度 = H − 3」是等价的——若最高的货物顶面 ≤ H−3，则顶层余隙必然 ≥ 3 cm。

## 4. 三条自加假设

| 编号 | 假设 | 题面状态 | 处理 |
|---|---|---|---|
| **A1** | 非易碎件底面最小接触比 | 未规定（P12 只说「无特殊约束」） | 主结果取 0%，扫描 0/25/50/75/100% |
| **A2** | 易碎件可否旋转 | 未规定（只对标准件写「可任意方向」） | 按可任意方向；最严格解释会进一步降低装载率 |
| **A3** | 任何货物不得悬空 | 未明写，物理必需 | 求解器与校验器均强制 |

**B1（建模近似，非假设）**：承重按接触面积均摊，未沿堆叠链累加。真实工况下力会往下传递，因此本实现偏宽松。

## 5. 坐标系

| 项 | 本项目 | 题面要求 |
|---|---|---|
| 原点 | 车厢左前下 `(0,0,0)` | 车厢**右后下** |
| x 轴 | 沿车长 | 同 |
| y 轴 | 沿车宽 | **方向相反** |
| z 轴 | 向上 | 同 |

导出 `solution.csv` 时必须做变换：`y_out = W − y − w`，并在文件头注明。否则评委按题面坐标读会判为错位（等价于全部箱子镜像，虽体积指标不变，但坐标校验会失败）。

## 6. 约束活跃性小结

| 约束 | 在本算例中是否起作用 | 证据 |
|---|---|---|
| C1 / C2 / C3 / C10 | 是（结构性，始终生效） | 基线 10 组配置全部通过 |
| C4 / C7 | 是（限定了姿态空间） | 定向件 90 件不可旋转 |
| **C5 / C6** | **是，且是主要瓶颈** | 27 件易碎件被挤到第二辆车 |
| C8 | 是（A1=0 时悬挑普遍，重心约束开始收紧） | 补齐后基线仍 0 违规 |
| **C9** | **否（不具约束力）** | 理论最大承压 353 kg/m² < 500 |

这张表本身就是一项可报告的成果：**十条约束中真正决定可行性的只有两条（C5/C6），而题面用大量篇幅描述的承重约束在本数据下毫无作用。**
