## 4. 实际运行接口与预算

另设30秒档；不能猜成 `--time-limit`。读取到的计时器使用CPU user+system，并另有墙钟记录。正式比较须串行运行并登记平台、Release配置、线程、完整命令和实际耗时；参数默认值的结果不自动等同论文经调参的配置。

**作者输出限制：** `include/sclp/Problem/Logs.hpp::make_output`导出逐件尺寸和位置，但不导出输入箱型/原件身份。项目适配器按允许姿态、类型数量恢复一组合法身份，且拒绝不同类型分配的歧义。该核验证明布局可对应合法输入，不声称恢复作者内部身份。

## 5. 输出身份适配已实现

新增 `experiments/adapt_guesser_output.py`。它不修改作者输出，而是把作者输出中的尺寸与位置转换为项目独立核验器所需的逐件记录：

1. 严格读取 `small_items[].measurement` 与 `position`，拒绝缺字段、非数值或非有限几何；
2. 按 thpack 类型的允许物理姿态建立候选源类型；
3. 用类型容量约束的迭代增广匹配求合法分配，再检查交替路径/环能否产生不同分配，避免逐件递归深度限制；
4. 若不存在合法匹配，或存在多个不同的源类型分配，直接拒绝，不按输出顺序伪造身份；
5. 对同一类型的可交换件只确定性分配 serial，随后调用 `verify_mes_result.verify()` 独立检查边界、重叠、姿态、数量、体积和指标。

适配器额外核对输出容器尺寸；CLI读取完整输入JSON并与源算例的规范转换逐字段匹配，不再按文件名推断身份。可用`--pid`消除重复输入的算例键歧义，但仍须通过内容核对。

最新协议测试19/19通过，包含真正触发歧义错误的用例、数量超限、非法姿态、NaN/Inf/布尔/负数/缺字段、容器或pid不符、250组固定随机种子的穷举匹配对照，以及1500件无逐件递归的测试。纠正历史测试说明：先前所谓“歧义”夹具因姿态flag错误，可能先在无候选类型处拒绝，不能据旧15/15记录声称该分支已覆盖。本轮已修正并用错误信息断言该分支。

真实作者示例和前三例输出均已通过身份、姿态、边界、无重叠、数量、体积和作者报告指标核验。
