## 2. 问题的标准分类：3D-MBSBPP

按 **Wäscher, Haußner, Schumann (2007), EJOR 183(3):1109-1130** 的 C&P 分类法（cutting and packing 领域的通用标准，取代了 Dyckhoff 1990 的旧分类）：

| 维度 | 取值 | 本项目的对应 |
|---|---|---|
| 维数 | 3D | 三维装箱 |
| 形状 | Rectangular | 全部为长方体 |
| 分配类型 | **Input minimization (IM)** | 给定全部货物，最小化容器使用 |
| 大物体（容器）种类 | **Multiple Bin Size (MBS)** | 车型 1、车型 2 两种规格 |
| 小物体（货物）种类 | **Strongly heterogeneous (SS)** | 5 类、300 件，每类件数不多 |

**标准命名：`3D-R-MBSBPP`（三维、长方体、多容器规格、装箱问题）。**

对照依据：Junqueira et al. (2012) 把单容器版本归为 `3/B/O/-`（Dyckhoff 旧法）或 `3D-R-IIPP/SLOPP/SKP`；LNS for CLP (2023, C&OR) 明确把"多规格容器"归为 **MSSCSP / MBSBPP**。

> **这一步的意义**：先说清问题属于哪个标准类别，别人才知道该用哪套术语和哪批文献来评价你。竞赛题里叫"多场景、多目标货物运输装箱策略优化"，学术上没有这个名字。

## 3. 公认的数学模型

### 3.1 为什么不能用竞赛题的写法

题面给的是**自然语言约束**（"易碎件仅允许单层放置"），这在学术上不算模型。公认模型必须写成 **MILP**（混合整数线性规划）或 CP（约束规划）的形式，且约束名称要对得上文献。

### 3.2 标准模型的结构（3D-MBSBPP 的最小形式）

**集合与参数**

| 符号 | 含义 |
|---|---|
| `I = {1..n}` | 物品（货物件） |
| `K = {1..m}` | 容器类型（车型） |
| `B = {1..\bar b}` | 可用容器实例（`\bar b` 为上界，如 `\bar b = n`） |
| `l_i, w_i, h_i` | 物品 i 的原始尺寸 |
| `m_i` | 物品 i 的重量 |
| `L_k, W_k, H_k` | 类型 k 容器的内尺寸 |
| `Q_k` | 类型 k 的载重上限 |
| `c_k` | 类型 k 的单次使用成本 |

**决策变量**

| 符号 | 含义 |
|---|---|
| `x_i, y_i, z_i ∈ Z+` | 物品 i 左下后角坐标 |
| `r_{i,o} ∈ {0,1}` | 物品 i 采用姿态 o（o 属于允许姿态集 `O_i`） |
| `β_{i,b} ∈ {0,1}` | 物品 i 装入容器实例 b |
| `u_b ∈ {0,1}` | 容器实例 b 被启用 |
| `k_b` | 容器实例 b 的类型 |

**目标（两种，对应题面问题 2 的两个小问）**

```
(P1) min  Σ_b u_b                          —— 车辆数最少
(P2) min  Σ_b c_{k_b} · u_b                —— 总成本最低
```

**核心约束（必须的）**

```
每个物品恰好装一次：        Σ_b β_{i,b} = 1                              ∀ i
每个物品恰好一个姿态：      Σ_{o∈O_i} r_{i,o} = 1                        ∀ i
装入才可定位：             z_i ≤ ... （big-M 与 β 联动）
容器内不重叠（析取）：      i,j 同容器时，四选一的分离不等式              ∀ i<j
容器边界：                x_i + 尺寸 ≤ L_k 等                            ∀ i
载重：                    Σ_i m_i β_{i,b} ≤ Q_k                          ∀ b
```

> 具体变量与 big-M 写法见 **Junqueira, Morabito, Yamashita (2012), C&OR 39(1):74-85**。该文的三项贡献正是本项目需要的：**cargo stability（垂直/水平）、load bearing strength、fragility**。

### 3.3 易碎件的标准数学定义（关键）

Junqueira et al. (2012) 原文对 fragile 的定义是：

> **fragility is the particular case of load bearing where boxes cannot be placed above a fragile box, since its top face does not bear any kind of pressure.**

即：**易碎件 = 顶面承压上限为 0 的承重特例。**

这给了我们一个可以直接引用的、公认的表达方式：

```
承重约束（一般形式）：
  对每件 i，其顶面承受的压强  p_i = (Σ_{j 直接压于 i} m_j · 接触面积占比) / A_i  ≤  P_i

  普通件：P_i = 500 kg/m²（题面给定）
  易碎件：P_i = 0            ← 这就是 fragility 的标准写法
```

**这条替换掉我们原来的 C5（"不可堆叠"），从口语描述升级为标准约束。**

### 3.4 稳定性的四种标准定义（我们只用了最严的一种）

C&OR (2025) 的对比研究列了四种底面支撑约束，并指出它们在装载效率上差异显著：

| 支撑定义 | 含义 | 本项目的对应 |
|---|---|---|
| **Full-base support** | 底面必须 100% 有支撑 | 我们的 **C6**（易碎件） |
| Partial-base support | 底面达到某个比例即可 | 我们的 **A1**（非易碎件，取 0%） |
| Center-of-gravity polygon support | 重心投影落在支撑多边形内 | 我们的 **C8**（定向件上方） |
| Partial-base polygon support | 部分底面积 + 多边形支撑 | 未用 |

**这解释了两件事**：
1. 我们的 A1=0（非易碎件接触比）在文献里对应"partial-base support 取 0"，是四种标准定义里最宽松的一档 —— 属于**已被文献识别、但少见的选择**，必须在报告中说明理由。
2. C6 用 full-base 是最严的一档，这正是易碎件难以安置的数学根源。

### 3.5 我们的 10 条约束 → 标准模型的映射

这张表是本文档的核心：它证明**约束不是自创的，是标准模型的实例化**。

| 我们的编号 | 题面原文 | 标准模型中的对应 | 文献出处 |
|---|---|---|---|
| C1 正交摆放 | 棱与箱体棱平行 | 姿态变量 `r_{i,o}`，仅允许轴对齐排列 | Wäscher 2007（rectangular） |
| C2 不重叠 | 不得重叠 | 析取分离约束（四选一） | Junqueira 2012 |
| C3 刚性不可拆 | 不可挤压、不可拆分 | 每件恰好装一次 | 标准 |
| C4 标准件任意向 | 可任意方向摆放 | `O_i = 6` 种排列 | 标准 |
| **C5 易碎件不可堆叠** | 仅单层、不可堆叠 | **load bearing 的 `P_i = 0` 特例** | **Junqueira 2012（fragility 定义）** |
| **C6 易碎件 100% 贴合** | 底面完全贴合 | **full-base support（垂直稳定性）** | **C&OR 2025 四类对比** |
| C7 定向件单姿态 | 仅一种摆放姿态 | `|O_i| = 1` | 标准（orientation constraint） |
| **C8 重心投影** | 上层重心不超下层投影 | **center-of-gravity polygon support** | **C&OR 2025** |
| **C9 承重 500** | 下层承重上限 | **load bearing strength `P_i = 500`** | **Junqueira 2012** |
| C10 高度与余隙 | 不超车厢、留 3cm | 容器尺寸约束（可用高 = H−3） | 标准 |
| A1 非易碎件接触比 | 题面未规定 | partial-base support，取 0 | C&OR 2025 |
| A3 不得悬空 | 题面未规定 | 支撑非空（避免 floating） | Junqueira 2012 |

**结论：10 条约束里有 4 条（C5/C6/C8/C9）属于稳定性与承重的标准约束族，全部有顶刊出处。** 这一点能在答辩时直接回应"你的建模是不是自己编的"。

## 4. SOTA 基线算法

按「期刊等级 × 是否可运行」两维筛选。

### 4.1 主推：可作为方法学基准的三篇

| 论文 | 期刊 | 问题类型 | 方法 | 报告指标 | 可运行性 |
|---|---|---|---|---|---|
| **Heßler, Hintsch, Wienkamp (2025)** | **EJOR** 327(3):820-837 | **3D-MBSBPP**（与本项目同型） | Randomized Greedy Search + 极值点插入 + 三维栅格加速 + first-fit | 优于前 SOTA；组件级消融 | 无公开代码，需自行实现 |
| **Guesser, Alves De Queiroz, Miyazawa (2026)** | **EJOR** 333(2):337-348 | 3D-SCLP（单容器） | beam search + double-effort + maximal empty space + guillotine block | **1600 算例 95.91% / 30s**；+0.59% over SOTA | **有代码**：`github.com/lucasguesserts/sclp-heuristic`（MIT） |
| **Junqueira, Morabito, Yamashita (2012)** | **C&OR** 39(1):74-85 | 3D-CLP（含稳定性/承重） | **MILP 模型** + 商业求解器 | 仅能解中等规模；用于验证模型正确性 | 无代码，但模型可直接照写 |

**用法分工**：
- Heßler 2025 = **算法基准**（同型问题，机制可直接对照）
- Guesser 2026 = **单容器装载率基准**（只对问题 1(1) 有效）
- Junqueira 2012 = **模型基准**（我们 MILP 形式化的依据，也是小规模精确解的来源）

## 5. 检索路径（怎么"顺着期刊找"）

老师的建议是一条可复用的方法，记录下来：

```
① 先定问题类别（Wäscher typology）→ 得到标准缩写 3D-R-MBSBPP
② 锁定 3–4 本顶刊：EJOR / C&OR / Operations Research / INFORMS JOC
③ 在期刊内用"问题缩写 + 约束关键词"检索
     3D-MBSBPP / container loading / load bearing / stackability / fragility
④ 找到最新一篇后，读它的 Related Work 与参考文献
     —— 这一步比检索更有效，因为它已经把领域地图画好了
⑤ 用 "cited by" 反向找更新的工作
⑥ 只保留两类：能给出可核查数字的、能提供标准模型的
```

**实践中最高效的一步是 ④**：Heßler 2025 的参考文献列表直接给出了 Paquay 2016/2018、Gajda 2022、Crainic 2008 这条主线。
