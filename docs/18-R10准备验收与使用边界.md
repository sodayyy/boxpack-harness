## 开测门槛

1. 至少两名真实参与者明确同意，登记经验、工具、模型版本及资料接触史；未同意不得采集聊天/录屏，不收集不必要身份信息。
2. 接触过具体任务或答案者不得将这些题作为未见评价集。docs12已可能披露类别比例，不能声称该比例对浏览过项目者保密。
3. 在工作副本绑定匿名槽位并另行冻结正式排程；保留本次准备包原字节，不把已绑定数据写回准备快照。
4. 组织者按排程逐题分发，不提供全部题库、配对映射、裁判实现或答案。AI条件使用无组织者上下文的新会话。
5. A为人工加非生成式工具，B为相同工具加生成式AI。阅读、提示、编码、审查和改错计入活跃时间；等待/暂停单记。单题活跃预算1800秒。
6. 组织者真人审核定量依据、漏检、误报、虚构与模型范围。超时未通过记未完成/右删失，不能把预算当成真实完成时间。
