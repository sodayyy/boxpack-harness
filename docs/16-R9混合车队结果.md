## 2. 最优性依据

450件体积43.1025m³，定向180件目录体积43.135m³，均大于单大车有效体积41.1502m³，所以至少2辆。费用低于1150元的全车型车队只有空车队、一小车、一大车或两小车等组合；两小车有效体积38.2788m³亦不足，故费用至少1150元。一小一大完整零违规见证同时达到两个独立下界，故当前操作模型P1=2、P2=1150。

这不是因为启发式穷举完整可行域，也不把容量松弛的可行性直接当成几何可行性。易碎45/60件和定向135件的单大车容量未被排除，故下界仍1辆/700元；新增1150元方案只缩小上界。

## 3. 方法与车序观察

旧`pack_blocks`保持等高车队约定不动。新增`pack_mixed_blocks`按声明车序逐车调用旧单车构造：按本车有效高度组块、保留已装货物、将未装货物在下一车重新组块。不跨车支撑，不额外开车，未使用车不收费。

这些同源确定性配置不作独立随机样本，不给统计显著性或一般车序优劣结论。与R8相比同时改变异高车队与剩余货物重组策略，不是车队类型的单因素因果对照。

## 4. 600件负结果

48项混合构造全部未装全。按已装件数最大、再按已装体积选择的描述性代表`mixed_067`装562/600件；小→大、height排序、xy优先、wide姿态序，剩38件：G4共24、G2共4、G3共10。该代表只描述本轮构造表现，不作为几何最大装载量、最少缺件或无解证明。

600件货物体积57.4700m³小于一小一大总有效体积60.2896m³，但余容不足以推出几何/支撑可行。后续可另登记货物分配或联合布局研究，也可选择更强有效下界；本轮不临时追加有利配置或改写协议。
