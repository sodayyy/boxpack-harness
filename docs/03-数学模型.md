# 03 数学模型 v2：三维多容器装箱与分层约束

> 本文是当前项目的正式建模口径。它把文献中的单容器模型、多容器扩展、题面硬约束、实验假设和算法实现分开。
> 文献基础：Junqueira, Morabito & Yamashita (2012), *Three-dimensional container loading models with cargo stability and load bearing constraints*, *Computers & Operations Research* 39(1):74–85；Alonso et al. (2019), *Computers & Industrial Engineering* 127:722–733。
> 当前仓库的 300 件问题使用启发式求解；本文给出通用模型语义和 L0 的混合整数骨架。L1–L4 的接触面积、逻辑联动、静力载荷等尚未完整线性化，也未实现精确求解，不能称为已完成可直接求解的全约束 MILP。

---

## 1. 问题身份和目标

当前问题是：

```text
3D-R-MBSBPP
Three-dimensional Rectangular Multiple-Bin-Size Bin Packing Problem
```

含义：三维、长方体货物、多种规格容器、输入最小化装箱问题。

原始题面没有客户节点、距离矩阵、时间窗和路线，因此路线不是当前主问题。车辆仅作为具有尺寸、载重和成本的容器实例出现。

给定全部货物，决定货物的：

1. 车辆类型和车辆实例；
2. 正交姿态；
3. 三维位置；
4. 支撑关系。

主问题有两个不应混淆的目标：

```text
(P1) 最少车辆数：min Σ u_{kb}
(P2) 最低运输成本：min Σ c_k u_{kb}
```

由于 3 辆车型 1 的成本为 1350 元，而 2 辆车型 2 的成本为 1400 元，车辆数和成本并不天然同向。报告必须分别独立求解P1和P2；P2不得限制在P1的最少车辆解集中。固定主/替代情景与实现边界见[协议v1](06-固定协议与验证口径.md)。

## 2. 题面约束、文献标准约束和实验假设

### 2.1 题面硬约束

| 编号 | 题面内容 | 模型表达 |
|---|---|---|
| C1 | 正交摆放 | 允许姿态只能是轴对齐排列 |
| C2 | 不重叠、不越界 | 车辆内三维区间分离和边界约束 |
| C3 | 刚性、不可拆分、数量守恒 | 每个具体货物恰好分配一次 |
| C4 | 标准件可任意方向、可堆叠 | 标准件姿态集合最多 6 种 |
| C5 | 易碎件单层、不可堆叠 | 易碎件顶面不得承受直接上层货物压力 |
| C6 | 易碎件底面完全贴合底面或标准件顶面 | 易碎件支撑面积比例为 100%，支撑来源受限 |
| C7 | 定向件仅允许一种姿态 | 定向件姿态集合只有 1 个元素 |
| C8 | 定向件上方货物重心不得超出投影 | 对规定的直接支撑关系检查重心投影 |
| C9 | 下层承重不超过 500 kg/m² | 局部承压约束，和车辆总载重分开 |
| C10 | 顶部预留 3 cm | 有效高度为 `H_k - 3` |

### 2.2 文献标准约束

- `α` 型垂直支撑比例：用于描述底面有多少比例被下方支撑面覆盖；
- `σ_i=0` 的易碎件承重特例：易碎件不能承受上方压力；
- full-base support、partial-base support、center-of-gravity polygon support：用于区分完全支撑、部分支撑和重心支撑；
- 车辆总载重、轴载、重心和动态稳定性：属于更完整的车辆装载模型，不应与题面 C9 混为一谈。

### 2.3 项目实验假设

| 编号 | 内容 | 当前处理 |
|---|---|---|
| A1 | 普通件最小底面接触比例 | 题面未规定；默认 `α=0` 作为项目主情景，另扫描 `0/25/50/75/100%` |
| A2 | 易碎件是否允许旋转 | 题面未明确；作为情景参数，分别报告固定姿态和允许姿态 |
| A3 | 普通件是否不得悬空 | 题面未明确；作为基本可执行性实验单独报告，不能说是题面原文 |
| B1 | 承重如何沿堆叠链传递 | 当前大规模实现按接触面积均摊；这是工程近似，不是完整材料力学模型 |

## 3. 集合和参数

### 3.1 具体货物

设 `N` 为具体货物个体集合。对于类型 `i` 有 `b_i` 件，可以展开为：

```text
n = (i,a),  a = 1,...,b_i
```

这样“数量守恒”不会被错误地简化成类型级别的模糊约束。

每件货物 `n` 有：

- 重量 `q_n`；
- 允许姿态集合 `O_n`；
- 姿态 `o` 下的尺寸 `(l_{no},w_{no},h_{no})`；
- 类型属性：标准件、易碎件或定向件。

### 3.2 车辆类型和实例

- `K`：车辆类型集合，当前 `K={1,2}`；
- `B_k={1,...,\bar b_k}`：车型 `k` 的候选车辆实例集合，`\bar b_k` 为数量上界；
- `(L_k,W_k,H_k)`：车辆内尺寸；
- `Q_k`：载重上限；
- `c_k`：使用一辆车型 `k` 的成本；
- `d=3 cm`：顶部预留。

### 3.3 其他集合

- `F ⊂ N`：易碎件集合；
- `D ⊂ N`：定向件集合；
- `S ⊂ N`：允许作为易碎件支撑面的标准件集合；
- `p_max=500 kg/m²`：题面局部承重上限。

## 4. 决策变量

```text
u_{kb} ∈ {0,1}
```
车型 `k` 的第 `b` 辆车是否启用。

```text
x_{nkb} ∈ {0,1}
```
货物 `n` 是否放入车辆 `(k,b)`。

```text
r_{no} ∈ {0,1}
```
货物 `n` 是否采用姿态 `o`。

```text
X_n,Y_n,Z_n ≥ 0
```
货物左下前角坐标。不同车辆实例的坐标通过 `x_{nkb}` 绑定到各自车厢。

```text
δ_{nm}^{a,+}, δ_{nm}^{a,-} ∈ {0,1},  a∈{x,y,z}
```
同车货物在某一轴向上的分离指示变量。

```text
s_{mn} ∈ {0,1}
```
货物 `m` 是否直接支撑货物 `n`。该变量在 L1 及以上层级启用。

```text
A_{mn} ≥ 0
```
货物 `m` 顶面与货物 `n` 底面的水平接触面积。

## 5. L0：刚体几何模型

### 5.1 姿态唯一

```text
Σ_{o∈O_n} r_{no}=1       ∀n
```

完整模型中，标准件的 `O_n` 可有最多 6 种；定向件只有题面指定的 1 种。为测量姿态约束代价，消融 L0–L2 放开定向件的六姿态，L3 起恢复固定姿态；`apply_level` 实现此切换。易碎件姿态为 A2 参数，现有基线默认允许六种。

### 5.2 每件货物恰好装一次

```text
Σ_{k∈K}Σ_{b∈B_k}x_{nkb}=1       ∀n
```

这与“单容器最大装载率”模型不同。本题主模型不是挑选子集，而是全部货物必须运输。若某个算法允许未装货物，必须显式报告未装件数，并标记为放松模型。

### 5.3 车辆启用关联

```text
x_{nkb}≤u_{kb}       ∀n,k,b
```

### 5.4 车厢边界

令姿态决定的尺寸为：

```text
l_n=Σ_o l_{no}r_{no},
 w_n=Σ_o w_{no}r_{no},
 h_n=Σ_o h_{no}r_{no}.
```

若 `x_{nkb}=1`，则：

```text
X_n+l_n≤L_k
Y_n+w_n≤W_k
Z_n+h_n≤H_k-d.
```

CP/CP-SAT 实现可使用可选区间变量；MILP 实现可用大 `M` 与车辆关联变量。两种写法表达同一边界语义。

### 5.5 同车不重叠

若货物 `n,m` 同属车辆 `(k,b)`，则必须至少在一个轴向完全分离：

```text
δ_{nm}^{x,+}+δ_{nm}^{x,-}
+δ_{nm}^{y,+}+δ_{nm}^{y,-}
+δ_{nm}^{z,+}+δ_{nm}^{z,-}
≥x_{nkb}+x_{mkb}-1.
```

每个 `δ` 再通过坐标不等式绑定，例如：

```text
X_n+l_n≤X_m+M(1-δ_{nm}^{x,+})
X_m+l_m≤X_n+M(1-δ_{nm}^{x,-}).
```

当前仓库使用整数占用栅格实现几何检查；该实现是离散算法版本，不是唯一的数学表达。

### 5.6 车辆载重

```text
Σ_n q_nx_{nkb}≤Q_ku_{kb}       ∀k,b.
```

总载重约束不能代替局部承重约束。

## 6. L1：支撑模型

对不在车厢底面的货物 `n`，使用支撑比例 `α_n∈[0,1]`：

```text
Σ_m A_{mn} ≥ α_n l_nw_n.
```

直接支撑必须满足：

```text
Z_m+h_m=Z_n,
```

支撑还必须满足**同车**与**真实接触面积**，不能把 `A_{mn}` 当作自由填充的面积变量。定义同车指示 `t_{nm,kb}=x_{nkb} AND x_{mkb}`，以三条标准二元线性约束联动；要求 `s_{mn}≤Σ_{k,b}t_{nm,kb}`。若 `s_{mn}=1`，则高度相接，且水平投影有正面积交集。

接触面积的几何定义为：

```text
a_x=max(0,min(X_m+l_m,X_n+l_n)-max(X_m,X_n))
a_y=max(0,min(Y_m+w_m,Y_n+w_n)-max(Y_m,Y_n))
A_{mn}=a_x*a_y   （仅同车且高度相接时；否则为 0）.
```

`min/max`、乘积和接触逻辑不是线性表达。精确实现需离散接触单元、分段线性化或专门约束建模；本仓库尚未交付该部分 MILP。地面支撑也需与 `Z_n=0` 联动。

实验口径：

- `α=0`：纯几何层，允许悬空，不能代表可执行装车；
- `α>0`：至少有支撑接触；
- `α=1`：完全底面支撑，适用于易碎件的 C6。

当前代码中的 L1“至少一格接触”是离散化操作定义，应在结果中明确说明，不能称为完整静态稳定性证明。

## 7. L2：易碎件

对每个 `n∈F`：

### 7.1 不承受上方压力（当前直接接触解读）

用文献中的承重特例表示：

```text
σ_n=0.
```

在直接支撑图中，易碎件不允许作为其他货物的承重支撑；当前 C5 只检查直接接触。允许其他支撑件托住、悬于易碎件上方的跨接货物，因此“易碎件上方整个柱体永久留空”是更强的额外假设，不可直接用于本模型的全局不可行性推导。

### 7.2 只能由底面或标准件支撑

```text
s_{mn}=0       ∀m∉S∪{floor}.
```

### 7.3 完全贴合

```text
Σ_{m∈S}A_{mn}+A_{floor,n}=l_nw_n.
```

如果落在车厢底面，则 `Z_n=0` 且 `A_{floor,n}=l_nw_n`。

这一层是当前研究的主要断点，但只能用“当前算法和算例下”限定结论，不能直接推出全局不可行性。

## 8. L3：定向件与重心

对定向件 `m∈D`，只允许题面规定的姿态。

若货物 `n` 直接位于定向件 `m` 上方，则其水平重心为：

```text
G_n=(X_n+l_n/2, Y_n+w_n/2).
```

要求 `G_n` 落在题面规定的定向件水平投影内。

多支撑情形必须提前固定口径：

- 保守口径：重心落在每个直接支撑件投影内；
- 几何口径：重心落在规定的支撑多边形内。

当前校验器逐一检查每个直接接触的定向支撑件，因此多支撑时属于保守口径；尚无独立的多支撑统计字段。默认均匀密度，几何中心作为重心投影，不代表已知真实质量分布。

## 9. L4：承重模型

承重有两个层次：

### 9.1 当前大规模近似 B1

代码实际采用：以**上层整块底面积**为分母分摊直接上层自重，再用**下层整块底面积**平均，并计入下层自重：

```text
carried_m = Σ_n q_n*A_{mn}/(l_n*w_n)
pressure_m = (q_m+carried_m)/(l_m*w_m*10^-4) ≤ 500 kg/m².
```

长度单位 cm，`10^-4` 转为 m²。它不是接触小区域的峰值压力，也不沿堆叠链传递载荷；部分支撑时分摊总量可能小于上层重量，因此不能称为力学守恒的严格载荷模型。当前独立校验与求解器在该近似上口径一致，不等于已验证真实物理安全。

### 9.2 载荷链后验检查（chain_area_v1，已实现）

对小规模实例可沿直接支撑图传递载荷：

```text
load_m=q_m+Σ_{n:m直接支撑n}load_{n→m},
```

`src/constraints.py::audit_load_chain`已实现自顶向下、按实际接触面积总和归一的竖向载荷传递、地面反力守恒和下层顶面平均外加载荷检查（不含下层自重）。主情景规定见协议06。它是独立后验审核，尚未接入求解器筛选；不保证力矩平衡、可优化接触反力或局部峰值压力。旧B1与新审核结果分别记录，不将它称为完整静力学模型。

不能把 B1 的“当前生成解未触发 C9”写成“所有合法堆叠都不会触发 C9”。

## 10. 目标函数

### P1：最少车辆数

```text
min Σ_{k,b}u_{kb}.
```

### P2：最低成本

```text
min Σ_{k,b}c_ku_{kb}.
```

### 两次独立求解与并列解展示

P1求最少车辆数，P2在原始完整可行域上重新求最低成本。两次结果分别报告车辆数、成本与校验状态。主目标并列时可以用另一指标选择展示方案，但这只是并列解展示规则，不能替代另一个独立目标。不得以词典序或未声明的加权和替代题面两项任务。

## 11. 分层实验与算法无关性边界

实验层级为：

```text
L0 刚体 → L1 支撑 → L2 易碎 → L3 定向/重心 → L4 承重。
```

每层实验尽量固定：

- 输入数据；
- 货物排序；
- 随机种子；
- 时间预算；
- 候选算法；
- 独立校验器。

但是，任何一次 L0–L4 结果都只是“在指定算法下的结果”。只有小规模精确模型、完整穷举或经过严格证明的上下界，才可以支持全局最优或全局不可行性结论。

## 12. 与当前实现的关系

| 内容 | 当前实现 | 正式解释 |
|---|---|---|
| 几何 | 整数占用栅格 | L0 的离散工程实现 |
| 候选位置 | 固定 7 角点 | EP-FF 弱基线的搜索限制 |
| 支撑 | 至少一格接触或参数化比例 | L1 的操作化定义 |
| 易碎 | 单层、标准件顶面、完全贴合 | L2 题面约束 |
| 定向重心 | 独立校验器检查 | L3 约束 |
| 承重 | 接触面积均摊 | L4 的 B1 近似 |
| 独立验证 | `src/constraints.py` | 最终结果裁判；旧 `pack_lib.verify()` 不作为最终证据 |

后续新增 B2/B3 算法必须复用同一个独立校验器，不能因为换了算法而换一套合法性标准。

## 13. 模型规模与用途

| 规模 | 用途 |
|---|---|
| 8–20 件 | CP-SAT/MILP/分支搜索精确验证 |
| 100 件左右 | 算法机制对比和小规模敏感性 |
| 300 件 | 启发式、Beam、块构造和车型组合扫描 |

当前 300 件实例不要求 MILP 直接给出全局最优。精确模型的作用是当“裁判”，而不是替代大规模算法。
