## 1. 问题的标准身份

按 Pisinger (2002) 的四分法（原文 §2），集装箱装载问题分四类：

| 缩写 | 名称 | 特征 |
|---|---|---|
| PCC2.5D | Strip Packing | 两个维度固定，一个可变 |
| PCC3D | Knapsack Loading | **单个**容器，挑子集装箱，最大化装载价值 |
| PCB | Bin Packing | 容器同尺寸同成本，最小化容器数 |
| **PCMC** | **Multi-Container Loading** | **容器不同尺寸、不同成本**，选子集并装箱，最小化总成本 |

**本题属于 PCMC**（车型 1/2 两种规格、成本 450/700），对应 Wäscher 等 (2007) 分类法的 `3D-R-MBSBPP`。

> 重要的边界：Junqueira 等 (2012) 原文明确「本文只处理 PCC3D」（"No presente trabalho tratamos apenas o PCC3D"）。**因此这篇给的是单容器模型，多容器部分需要我们自己扩展**——这既是工作量，也是可声明的增量。

## 2. 符号

### 2.1 原始参数（题面给定）

| 符号 | 含义 | 本题取值 |
|---|---|---|
| `L, W, H` | 容器内长、宽、高 | 车型 1: 420, 210, 220；车型 2: 680, 245, 250 |
| `m` | 箱型数 | 5（G1–G5） |
| `l_i, w_i, h_i` | 类型 i 的尺寸 | 见 `data/items.csv` |
| `b_i` | 类型 i 的件数 | 80/100/30/40/50 |
| `v_i` | 类型 i 的价值 | 取 `l_i·w_i·h_i`（即最大化体积） |
| `P_j` | 类型 j 的单件重量 | 12/8/15/25/18 kg |
| `σ_i` | 类型 i 顶面**每点**可承受的最大压力 | 普通件 500 kg/m²；**易碎件 0** |
| `α` | 垂直稳定性参数 ∈ [0,1] | 见 §4 |
| `Q` | 容器载重上限 | 6000 / 10000 kg |
| `c_k` | 类型 k 容器单次成本 | 450 / 700 元 |

### 2.2 位置集合（原文式 (1)–(6)）

由于所有尺寸取整数，位置可以离散化：

```
X = {0, 1, ..., L − min_i(l_i)}      所有可能的 x 起点
Y = {0, 1, ..., W − min_i(w_i)}
Z = {0, 1, ..., H − min_i(h_i)}

X_i = {p ∈ X | 0 ≤ p ≤ L − l_i}      类型 i 允许的 x 起点
Y_i = {q ∈ Y | 0 ≤ q ≤ W − w_i}
Z_i = {r ∈ Z | 0 ≤ r ≤ H − h_i}
```

原文进一步引用 Christofides & Whitlock (1977) 的**正常模式（normal patterns）**缩减集合（式 (4)–(6)）：任何可行解都可平移成「每个箱子都紧贴另一个箱子或容器壁」的形式，因此 `X` 可缩减为各型号尺寸的组合 `{Σβ_i·l_i}`。这一步把变量数量降低一个量级。

### 2.3 预计算函数（非决策变量，原文 §3）

```
a_{i,p,q,r,s,t,u} = 1  若类型 i 的箱子放在 (p,q,r) 时，会占据点 (s,t,u)
c_{i,p,q,r,s,t,(r+h_i)} = 1  若该箱子放在 (p,q,r) 时，其顶面覆盖点 (s,t,r+h_i)
```

`a` 用于非重叠判定，`c` 用于支撑判定。两者都可在求解前算好。

### 2.4 决策变量

| 符号 | 域 | 含义 |
|---|---|---|
| `x_{ipqr}` | {0,1} | 类型 i 的箱子，左下前角放在 (p,q,r) |
| `β_i` | 整数 | 类型 i 实际装入的件数（可由 `x` 推出，为便于阅读保留） |

## 3. 基础模型（原文式 (10)–(13)，等价形式 (14)）

```
max   Σ_i v_i · Σ_{p∈X_i} Σ_{q∈Y_i} Σ_{r∈Z_i} x_{ipqr}                    (10)

s.t.  Σ_i Σ_{p,q,r} a_{i,p,q,r,s,t,u} · x_{ipqr} ≤ 1
                                     ∀ (s,t,u) ∈ X×Y×Z                     (11)
      非重叠：每个格点最多被一个箱子占据

      Σ_{p∈X_i} Σ_{q∈Y_i} Σ_{r∈Z_i} x_{ipqr} ≤ b_i          ∀ i           (12)
      数量：不超过该型号的件数

      x_{ipqr} ∈ {0,1}                                                     (13)
```

原文指出，(11) 需要预计算 `a` 会吃掉大量内存（他们用 GAMS 编译失败），因此给出**等价形式 (14)**，把范围直接写进求和下标：

```
Σ_i  Σ_{p ∈ X_i, s−l_i+1 ≤ p ≤ s}
     Σ_{q ∈ Y_i, t−w_i+1 ≤ q ≤ t}
     Σ_{r ∈ Z_i, u−h_i+1 ≤ r ≤ u}
        x_{ipqr}  ≤  1        ∀ (s,t,u) ∈ X×Y×Z                            (14)
```

**这就是本文采用的形式**——不需要预计算，直接按几何范围求和。

> 若 `v_i = l_i·w_i·h_i`，(10) 等价于「最大化装入的总体积」，也就是最大化装载率。

## 4. 垂直稳定性（原文式 (15)）——我们的 A1 就在这里

原文引入**垂直稳定性参数 `α ∈ [0,1]`**（引自 Eley 2002）：

> `α = 1`：所有箱子底面必须 100% 被下方箱子的顶面支撑；
> `α = 0`：不做稳定性要求，箱子可以部分支撑，**甚至可以悬空**（"podem estar apenas parcialmente apoiadas, ou mesmo 'flutuando'"）。

约束形式：

```
Σ_i Σ_{p,q} c_{i,p,q,(r−h_i),s,t} · x_{i,p,q,(r−h_i)}
        ≥  α · l_j · w_j · x_{j,p',q',r'}
                    ∀ j, ∀ (p',q',r') ∈ X_j × Y_j × Z_j / {0}            (15)
```

含义：箱子 `j` 若放在 `(p',q',r')`，则其底面被下方箱子顶面覆盖的格点数，必须 ≥ `α` × 它的底面积（格点数）。

**这一条直接消解了我们之前的困惑：**

| 我们的说法 | 文献里的标准名 | 结论 |
|---|---|---|
| 「假设 A1：非易碎件最小接触比，题面未规定」 | **垂直稳定性参数 α**（Eley 2002；Junqueira 2012 式 15） | **不是自创假设，是标准参数的一个取值** |
| A1 = 0（我们原来的默认） | `α = 0` | 文献明说这一档「允许悬空」，所以我们关掉悬空检查后跑出 99.5% 的虚高，是 α=0 的正常后果 |
| C6：易碎件底面 100% 贴合 | `α = 1`（对所有箱子） | 我们用的是一个"全局限 α=1、但只对易碎件生效"的变体 |

> **报告里应当改写**：不要说「A1 是本文假设」，要说「本文取 `α = 0`（对普通件）与 `α = 1`（对易碎件）的**分组稳定性参数**，这是对式 (15) 的自然推广」。

## 5. 承重与易碎（原文式 (18)）

原文假设：
- 上方箱子的重量**均匀分布**在其底面 `l_j × w_j` 上；
- 类型 i 顶面**每一点**的允许压力相同，记为 `σ_i`。

约束形式：

```
Σ_j (P_j / (l_j·w_j)) · Σ_{p ∈ X_j, s−l_j+1 ≤ p ≤ s}
                       Σ_{q ∈ Y_j, t−w_j+1 ≤ q ≤ t}
                       Σ_{r ∈ Z_j, r > u}
                          x_{j,p,q,r}
    ≤  σ_i · (点 (s,t,u) 被类型 i 占据的指示)         ∀ (s,t,u) ∈ X×Y×Z   (18)
```

含义：对容器里的每个格点，其上方的总压力不得超过所在箱子的允许压力。

### 易碎件的标准处理（原文 §3.2 末段）

> 「Um caso particular de empilhamento é a chamada **fragilidade**. Neste caso, nenhuma caixa deve ser colocada acima da caixa de referência, pois a face superior desta não pode sofrer nenhuma pressão. Para tratar deste caso, basta considerar **σ_i = 0** para cada caixa frágil do tipo i.」
>
> （易碎是承重的一个特例：参考箱上方不得放任何箱子，因为其顶面不能承受任何压力。处理办法是**令该类型的 σ_i = 0**。）

**这就是我们 C5 + C9 的标准表达：**

```
普通件：σ_i = 500 kg/m²          （题面给定的承重上限）
易碎件：σ_i = 0                  （= 上方不能有任何箱子，等价于「不可堆叠」）
```

原文还强调：承重模型要求 `α = 1`，否则会出现"空洞"，压力计算失真。

## 6. 多容器扩展（本文增量）

原文只做 PCC3D（单容器）。我们的题是 PCMC，需要加一层容器维度：

### 6.1 新增参数

```
K = {车型1, 车型2}                容器类型集合
(L_k, W_k, H_k)                   类型 k 的尺寸
Q_k                               类型 k 的载重
c_k                               类型 k 的单次成本
B = {1, ..., \bar b}              容器实例集合，\bar b 为上界（如 ⌈Σ体积 / min V_k⌉）
```

### 6.2 新增变量

```
y_{i,p,q,r,k,b} ∈ {0,1}    类型 i 的箱子放在容器实例 b（类型 k）的位置 (p,q,r)
u_{k,b} ∈ {0,1}            容器实例 b 被启用且为类型 k
```

### 6.3 修改后的约束

```
每个箱子恰好装一次（因为全部货物必须运完，不是挑着装）：
    Σ_{k,b} Σ_{p,q,r} y_{i,p,q,r,k,b} = b_i          ∀ i                  (12')

每个容器内不重叠（逐容器判定）：
    Σ_i Σ_{范围内 p,q,r} y_{i,p,q,r,k,b} ≤ 1
                              ∀ (s,t,u), ∀ (k,b)                          (14')

容器启用与箱子关联：
    y_{i,p,q,r,k,b} ≤ u_{k,b}                          ∀ i,p,q,r,k,b       (14'')

载重：
    Σ_i P_i Σ_{p,q,r} y_{i,p,q,r,k,b} ≤ Q_k · u_{k,b}  ∀ (k,b)             (16)
```

### 6.4 两个目标（对应题面问题 2 的两个小问）

```
(P1) 车辆数最少：  min  Σ_{k,b} u_{k,b}
(P2) 成本最低：    min  Σ_{k,b} c_k · u_{k,b}
```

### 6.5 题面特有、文献没有的两条

| 我们的约束 | 处理方式 |
|---|---|
| **C8 定向件上层货物重心不得超出其投影** | 原文无此约束。对应 C&OR (2025) 四种支撑定义中的 **center-of-gravity polygon support**。可在式 (15) 上加一条：若下层箱为定向件，则上层箱的重心投影点必须落在其矩形内 |
| **A2 易碎件可否旋转** | 原文为简化假设「orientações são fixas」（姿态固定，§3 开头），并说明可放松。我们的处理是给每个类型一个允许姿态集合 `O_i`，把 `x_{ipqr}` 扩展为 `x_{i,o,p,q,r}` |

## 8. 模型规模与用途

原文报告：基础模型变量数为 `Σ_i |X_i|·|Y_i|·|Z_i|`，约束数同量级；作者的实验表明 **CPLEX 只能解中等规模**，且件数一大就不可解。

对本题的估算：

| 规模 | 变量数量级 | 可行性 |
|---|---|---|
| 15–20 件 | 10⁴–10⁵ | 可用 CBC / GLPK / HiGHS 求解（分钟级） |
| 100 件 | 10⁶–10⁷ | 求解器内存不足 |
| 300 件（本题） | ≫10⁷ | **不可解** |

**因此 MILP 在本项目中的定位是：**
1. **形式化依据**——报告第 3 节引用它，证明约束不是自创的；
2. **小规模精确解**——在 15–20 件算例上求最优，用来校准启发式差多少（N3 的"精确解校验"）；
3. **不是主求解器**——300 件必须走启发式。

## 9. 与文献的差异（可声明的增量）

| 差异 | 说明 |
|---|---|
| **单容器 → 多容器** | 原文是 PCC3D，我们扩展到 PCMC（§6） |
| **分组稳定性参数** | 原文 α 全局唯一；我们对易碎件取 1、其他取 0，是分组化 |
| **加 C8 重心投影** | 原文无，需引 C&OR 2025 |
| **目标不同** | 原文最大化装入价值（挑着装）；我们是全部装完 + 最小化车辆数/成本 |
| **规模不同** | 原文算例 ≤20 类型、中等规模；我们 300 件，必须启发式 |

这五条写进报告第 3 节和第 7 节（创新点与局限）。
