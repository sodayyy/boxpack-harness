# 固定协议与验证口径 v1

初版日期：2026-11-10；实现状态更新：2026-11-11。该协议固定后续实验语义；旧结果保留原版本，不重新贴标签。规则依据与未定数据来源见01、03。

## 1. 研究任务与目标

以附件1五类300件货物为主研究数据；主线保留多车和两种车型，先几何再增加约束。P1最少车辆数、P2最低运输成本分别独立求解；P2不限制在P1最少车辆集合。并列最优解可以用另一指标选择展示方案，但不得将展示规则当作题面优先级。没有路线优化。

原题还包含两车型各自单车最大装入体积和同型车全运输任务；单容器允许选子集，多车运输必须全量守恒。附件2缺少数量、重量等字段，暂不作为完整全约束外部验证。

## 2. 主情景与替代情景

主情景是明确声明的研究约定，不代表题面唯一解释。

| 项 | 主情景 | 替代/敏感性情景 |
|---|---|---|
| 几何 | 刚性轴对齐长方体；cm、kg；输入整数尺寸 | 其他网格精度需另设版本 |
| 易碎单层 | 顶面禁止直接接触承压；不禁止由别件托住且不接触的跨接 | 上方投影整柱禁放，作为更强假设 |
| 易碎姿态 | 允许尺寸的六种去重排列，延续已有实现 | 固定原始姿态；未规定不等于题面授权六姿态 |

## 3. 承重模型的版本

旧`legacy_b1`：直接上层自重乘接触面积/上层整底面，下层自重加分摊量除下层整底面。保留旧实验，不作严格安全依据。

`chain_area_v1`定义如下，已同时实现版本化求解筛选和独立后验检查：

1. 对上件n的所有同高接触支撑m，计算A_mn，令S_n=Σ_m A_mn。
2. 自顶向下，T_n=q_n+Σ_{j:n支撑j}F_{j→n}；F_{n→m}=T_n A_mn/S_n。
3. 非地面货物S_n=0判为不守恒；在正接触下每层Σ_m F_{n→m}=T_n。落地货物反力R_n=T_n，Σ_floor R_n=Σ_n q_n。
4. 下层顶面平均外加载荷为(T_n−q_n)/(l_nw_n×10^-4)，要求≤500kg/m²；不含本件自重。易碎件顶面外加载荷为0。地面对本件自重的承载不是题面下层箱体顶面承重。

此为固定比例的竖向载荷传递近似；分母采用下层整顶面，仍不是局部峰值压力，也未保证力矩平衡。接触面积分配不是反力优化；可能存在其他分配，但本模型只评价这一种。历史`Truck`仍按B1筛选并保留旧结果；新增`ChainTruck`逐候选独立重算全部实际接触和载荷链，包含插入旧上件下方产生的新支撑。最终由`constraints.py`独立裁判。新结果使用`chain_single_L0`至`L4`及`chain_mixed_L4`独立版本，审核不通过不能当新模型可行证据。

## 4. 理论模型、网格与搜索

理论坐标模型允许实数；占用网格当前为1cm整数坐标。有限网格裁判仅在声明的整数网格、姿态、单容器L0目标下完整搜索。EP固定角点、B2互斥分区+有界Beam进一步限制搜索位置。

可行布局经验证支持存在性；启发式失败不证明不可行。承重/支撑加入后不能直接沿用纯几何网格完备性。L0–L4增加约束时理论可行域逐层缩小；启发式输出不是理论最优值。

## 5. 目录身份、坐标与指标

输入目录决定型号尺寸、重量、属性和数量；标准身份为`G1-000`等（每型0至qty−1）。逐车结构校验和跨车全局身份/数量均须检查。不能信任求解结果自行填写的重量或kind。

内部原点左前下，x由前向后、y由左向右、z向上。输出原点右后下，x由后向前、y由右向左、z向上。坐标表示在各自轴上较小的货物角点：

```
x_out=L−x−l; y_out=W−y−w; z_out=z.
```

转换为自逆映射，尺寸不变。JSON记录schema、轴向、车型与层级；CSV每行记录坐标系和车型。导出后读回，与原始布局逐件比对，并重新独立验证。

- nominal_space_util=已装体积/已用车辆标称容积；题面空间满载率使用此口径。
- effective_space_util=已装体积/扣顶部余隙后的可用容积。
- shipment_completion=已装体积/本批总体积；不是满载率。
- weight_util=已装重量/已用车辆载重容量。
- 未装件、违规数、车辆数、成本单独报告；不完整装运不得当作全运输目标候选。
- 体积下界用有效容积，利用率分母另行记录；不能因下界用了有效容积就默默改空间指标分母。

## 6. 几何强基线比较

数据：BR/thpack按原有尺寸、数量和竖直方向flags；单容器、轴对齐、只评价几何与允许姿态、无题面3cm余隙、无重量/支撑/易碎/承重限制。

原先前三例已经反复用于调试，thpack1全100例EP结果也已查看，不能再声称thpack1某子集为从未见过的盲测。固定分工：thpack1第1–10例用于开发/冒烟；第11–100例为冻结参数比较集（已见过EP结果，披露这一点）。thpack9另作为后续泛化评估；在启用前登记已查看/使用范围，不能保证绝对未见。最终比较后再调参数需另设版本并披露。

优先运行Guesser固定提交与Araya固定提交，先作者示例和thpack1前三例冒烟，再扩展冻结比较集。作者算法使用相同单核CPU时间预算5秒与30秒两档；原程序若用CPU时间，必须另记墙钟时间。EP为一次确定性构造，可报告提前终止及实际时间；B2为状态预算，未实现中断前只作配置对照，不混成严格相同时间榜单。各算法串行运行，记录CPU/OS/编译器/Release选项/线程与实际命令；重复运行和seed可用性按作者接口记录，禁止杜撰随机参数。

强基线必须保存逐件布局并核验数量上限、允许姿态、边界、不重叠、体积汇总。不输出可核验布局的程序只报告指标级运行，标记未完成布局验证。下载可得、编译成功、实际求解和复现论文统计是四个不同阶段。
