# 数据说明

## 文件

| 文件 | 内容 | 行数 |
|---|---|---|
| `items.csv` | 5 类货物的尺寸、单重、数量 | 5 行数据 |
| `trucks.csv` | 2 种车型的内尺寸、容积、载重、成本 | 2 行数据 |

## 字段

**`items.csv`**

| 字段 | 含义 | 单位 |
|---|---|---|
| 编号 | 货物型号（G1–G5） | — |
| 类型 | 标准件 / 易碎件 / 定向件 | — |
| 长_cm / 宽_cm / 高_cm | 原始尺寸（定向件即其唯一允许姿态） | cm |
| 单重_kg | 单件重量 | kg |
| 数量 | 该型号件数 | 件 |
| 单件体积_m3 / 总体积_m3 | 由尺寸推算，便于核对 | m³ |

**`trucks.csv`**

| 字段 | 含义 | 单位 |
|---|---|---|
| 车型 | 车型1（轻型）/ 车型2（中型） | — |
| 内长/内宽/内高_cm | 车厢内尺寸 | cm |
| 容积_m3 | 内尺寸乘积 | m³ |
| 额定载重_kg | 载重上限 | kg |
| 单次成本_元 | 每趟运输成本 | 元 |

## 自检

运行 `py -3.12 experiments/run_baselines.py` 会校验：

- 件数合计 = **300**
- 体积合计 = **28.735 m³**
- 重量合计 = **4,110 kg**

与本表逐行对应。

## 为什么没有原始附件

原始材料（题目 PDF、`附件1.docx`、`附件2：验证数据集.xlsx`）**不入库**，原因有两条：

1. **版权**：题目与附件为 MathorCup 赛事材料。
2. **保密**：附件 2 为企业真实数据（8 种机油箱装尺寸），且同一件货给出「化验测量」与「仓库实测」两套尺寸。

本目录的 CSV 是从题面抄录后的**最小可复现数据集**：足以复算本项目的全部数字，但不含企业原始记录。若需引用附件 2 做大规模验证，请自行向赛事主办方获取。
