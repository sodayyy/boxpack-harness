# 参数化三维装箱：统一模型、形式化核验与参数研究

## 一、快速阅览

**研究问题：** 给定货物与多种车型，在几何、支撑、易碎、定向和承压约束下，分别求最少车辆数与最低运输费用，并分析参数变化对可行性和方法表现的影响。

**统一模型：** 令 $`\mathcal D`$ 表示货物与车型数据，$`\theta=(\alpha,p,\delta,\rho,\kappa)`$ 表示参数，$`\ell`$ 表示约束层级。两个目标在同一可行域内独立优化：

$$
\boxed{\begin{aligned}
V_r(\mathcal D,\theta,\ell)
&=\inf_{\xi\in\mathcal F_\ell(\mathcal D,\theta)}\sum_{v\in V}w_{rv}u_v,\\
w_{1v}&=1,\qquad w_{2v}=c_{k(v)},\qquad r\in\{1,2\}.
\end{aligned}}
$$

$`V_1`$ 是最少车辆数，$`V_2`$ 是最低运输费用；两者分别求解，不加权、不作词典序优化。

| 研究内容 | 当前结果 |
|---|---|
| 数学建模 | 一个参数化可行域，逐层启用几何、支撑、易碎、定向和载荷约束 |
| Lean | 8个算术/容量声明与8个抽象参数定理已检查构建；尚未形式化完整三维几何和具体布局 |
| 文献与基线 | Guesser作者程序运行100例；Metasolver运行开发集10例；另比较本题完整约束下的三种方法 |
| 计算实验 | 16场景×3方法、每组最多30秒；带帽块法16/16得到完整解，13/16双目标达到下界 |
| 参数研究 | 分开报告最优值界、固定布局覆盖和预算内方法表现；270个参数点评估不是270次新求解 |
| 已证结论 | 原300件在 $`0\le\alpha\le1`$、$`p\ge1900/7\approx271.43\ \mathrm{kg/m^2}`$、$`0\le\delta\le30\ \mathrm{cm}`$ 内，$`V_1=1`$、$`V_2=700`$ |
| 未闭合问题 | 600件费用仍为[1150,1400]元；易碎60件费用仍为[700,1150]元；尚无完整连续相图 |

结论限于本文定义的操作模型。计算实验不是运输动力学仿真；一份布局的阈值也不是全局可行边界。

## 二、详细展开

### 2.1 问题与数据

研究对象是**全部货物必须运输的多规格容器正交装箱**，车辆作为带尺寸、载重和费用的容器，不含路线规划。

原始实例有5类、300件货物，总体积28.735 m³、总质量4110 kg。车型为小车420×210×220 cm、载重6000 kg、费用450元；大车680×245×250 cm、载重10000 kg、费用700元。货物明细见[竞赛数据与文献基线](docs/02-文献与建模基线.md)。

参数含义：$`\alpha`$ 为非易碎件底面支撑比例，$`p`$ 为顶面平均外载上限，$`\delta`$ 为顶部余隙；$`\rho`$ 与 $`\kappa`$ 分别指定姿态和接触/传力规则。原主情景为L4、$`(\alpha,p,\delta)=(0,500,3)`$；方法比较基准为L4、$`(1,350,3)`$，二者不同。

### 2.2 统一模型与约束

决策状态 $`\xi`$ 包含车辆启用、货物分配、姿态与坐标；接触关系和载荷由几何及规则导出。可行域按同一模型分层：

| 层级 | 累计约束 |
|---|---|
| L0 | 分配、姿态、容器边界、不重叠、车辆载重 |
| L1 | L0＋非落地货物有正面积直接支撑 |
| L2 | L1＋普通件支撑比例与易碎件支撑规则 |
| L3 | L2＋定向件原姿态及接触投影规则 |
| L4 | L3＋竖向载荷链与承压上限 |

几何决定真实接触；支撑边不能任意删除。载荷按实际接触面积向下分配，并检查平均外载和地面反力守恒。该规则不等同于力矩平衡、局部峰值压力、摩擦或运输动力学安全。

完整变量、集合、约束公式、单位与适用边界见[统一参数化模型](docs/19-统一参数化模型.md)。这里保留主模型和机制说明，不重复铺开每条几何公式。

### 2.3 最优性与Lean

参数放松时的可行域包含关系，给出两个最小化目标的单调性。对原300件，非空运输至少需要一辆；费用低于700元只能使用空车或一辆小车，而小车容积小于货物总体积，故费用下界为700元。已核验的一大车布局同时达到车辆数与费用下界，因此在快速阅览列出的参数区域内，两个目标分别闭合。

Lean实际构建检查覆盖了若干算术/容量下界，以及抽象参数阈值和最优值性质。它尚未形式化完整三维几何、300件坐标、接触面积或载荷递推，不能表述为整个装箱问题已形式化证明。

证据与覆盖范围见[Lean核验记录](experiments/results/method_study_20261116_v1/lean-verification.json)及[统一模型文档](docs/19-统一参数化模型.md)。

### 2.4 文献基线与本题方法

文献按目标、约束和复现深度匹配，不按装载率直接排名。几何作者基线包括Guesser与Metasolver；它们处理单容器几何装载，与本题全货物、多车辆、成本目标并不等价。

| 路线 | 实际范围 | 说明 |
|---|---|---|
| Guesser作者程序 | OR-Library 100例，5秒与30秒预算 | 几何基线；全100例为描述性汇总 |
| Metasolver作者程序 | 开发集10例，5秒与30秒预算 | 未运行其余90例，不与Guesser作同样本排名 |
| 逐件EP多排序 | 本题16个场景 | 项目实现，不是经典EP论文完整复现 |
| 无帽柱块 | 本题16个场景 | 带帽块方法的机制消融 |
| 压力感知带帽块 | 本题16个场景 | 以压力规则构造块并逐件核验 |

作者版本、运行协议、指标与比较限制见[作者基线复现记录](docs/07-作者基线复现记录.md)和[文献依据](docs/02-文献与建模基线.md)。

### 2.5 计算实验与核验

固定L4完整约束，16个场景、3种方法，每组30秒上限，并记录10秒与30秒检查点。场景覆盖原300件的压力、余隙和支撑切片，以及450件、600件和货物组成变体。

| 方法 | 30秒内完整解 | 双目标同时达到下界 |
|---|---:|---:|
| 逐件EP多排序 | 12/16 | 0/16 |
| 无帽柱块 | 15/16 | 0/16 |
| 压力感知带帽块 | 16/16 | 13/16 |

实验共900次候选尝试：489个完整、380个部分、31个预算超时，无执行错误。869份候选被重新读回核验，文件摘要检查5422项通过。实验是已知货型上的单次开发运行，不是盲测、重复随机统计或速度显著性检验。没有完成动力学仿真。

协议、矩阵复核和恢复验收见[实验记录](experiments/results/method_study_20261116_v1/)。

### 2.6 参数区域与主要结论

参数结果分三类：原问题最优值上下界、保存布局池的适用区域、固定预算下的算法表现。三者不可混称为一张完整相图。

保存布局池评估270个参数点：147点双目标达到下界，45点只有可行上界，78点未被池覆盖。未覆盖不等于无解，也不代表进行了新的求解。

原300件的一大车布局给出已证明区域：$`0\le\alpha\le1`$、$`p\ge1900/7`$、$`0\le\delta\le30`$ 时，$`V_1=1`$ 且 $`V_2=700`$。$`1900/7`$ 是该布局的压力阈值，不是全局最低压力。已测预算点没有出现最佳方法排名切换；EP补充了部分低压力布局覆盖，但不足以证明所有参数区都需要切换算法。

| 场景 | 最少车辆数 $`V_1`$ | 最低费用 $`V_2`$ |
|---|---:|---:|
| 原300件 | 1 | 700元 |
| 450件 | 2 | 1150元 |
| 600件 | 2 | [1150,1400]元 |
| 易碎件增至60件 | [1,2] | [700,1150]元 |
| 定向件增至180件 | 2 | 1150元 |

区间表示下界与已知可行上界尚未闭合，不意味着区间内每个值都可达。数量变化同时影响体积、质量和组成，不作单因素因果解释。结果数据见[参数研究记录](experiments/results/method_study_20261116_v1/研究结果.html)。

### 2.7 结论与未完成事项

当前研究已将统一模型、有限形式化、作者基线、同预算计算实验、参数区域和布局核验连接起来。原300件的一个参数区域已分别证明P1与P2最优；若干变体仍保留上下界。

尚未完成完整连续相图、一般实例全局最优算法、全部三维几何的Lean形式化、运输动力学仿真，以及吸收最新结果的论文定稿。历史材料与失败记录保存在[归档目录](docs/archive/)，当前入口只保留研究问题与已核验证据。
